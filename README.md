## 🛠️ Installation

### Prerequisites:
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection (for external resources)
- Text editor or IDE (VS Code recommended)

### Quick Start:

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/yourusername/rabha-stones.git
   cd rabha-stones
   ```

2. **Open in Browser:**
   ```bash
   # Simply open index.html in your browser
   # Or use Live Server in VS Code
   ```

3. **No Build Process Required!**
   - The project is a vanilla HTML/CSS/JavaScript solution
   - No npm packages or build tools needed
   - Works directly in any modern browser

### Folder Structure:
```
rabha-stones/
├── index.html          # Main HTML file
├── style.css           # Complete styling
├── main.js             # JavaScript functionality
├── README.md           # This file
└── assets/
    └── (images handled via CDN)
```

## 🔧 Customization

### Update Product Data:
Edit in `main.js` - Translations section:
```javascript
prod_ring1_name: "Your Ring Name",
prod_ring1_price: "Price in EGP",
prod_ring1_desc: "Product description",
prod_ring1_rating: "Rating"
```

### Change Colors:
Modify CSS variables in `style.css`:
```css
:root {
    --primary-gold: #D4AF37;
    --primary-dark: #1a1a1a;
    --secondary-light: #f5f5f5;
}
```

### Add New Products:
1. Add product data to translations
2. Update product grid HTML
3. Images load dynamically from URLs
